# Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `sync` workspace: the commands `auth <bank>`, `sync` and `status`, fetching booked transactions through the Enable Banking API into the archive, tested end to end against an in-memory fake bank.

**Architecture:** Every fetch has two phases joined only by an inbox on disk: pages are written as received, then merged from disk, so a fresh fetch and one left by a crash take the same path. Pure modules (settings, token, response validation, fetch window, missing records, consent) are wrapped by thin I/O modules (inbox, state, lock, client) and three commands. `main(argv, env, deps)` receives `fetch`, the clock, the terminal and the process table as arguments, so the Tier 2 tests run the real commands against the fake bank in a temporary directory.

**Tech Stack:** Node.js ≥ 24.12 running TypeScript directly (type stripping, no build), `node:test`, `node:assert/strict`, `node:crypto`, `node:fs/promises`, the built-in `fetch`. No runtime dependency beyond `@money/shared`. No new development dependency.

**Spec:** [docs/specs/2026-10-11-sync.md](../specs/2026-10-11-sync.md). The design it builds is [docs/sync.md](../sync.md); the format it writes is [docs/archive-format.md](../archive-format.md). Read all three, [docs/testing.md](../testing.md) and `CLAUDE.md` before starting.

## Global Constraints

- **Work in the worktree** `.claude/worktrees/sync`, on branch `worktree-sync`. `npm ci` has been run there. Never `cd` to the main checkout while building.
- **`@money/sync` depends on `@money/shared` and nothing else.** No new dependency of any kind, runtime or development.
- **Erasable TypeScript only:** no `enum`, `namespace`, parameter properties. Relative imports carry the `.ts` extension. Type-only imports use `import type`.
- **Only `sync/src/cli.ts` reads `process.env`, `process.argv`, the real clock, the real `fetch` or stdin.** Everything else takes them as arguments.
- **No retries, anywhere.** One request per page, and a failure is a failure.
- **No PSU headers are sent** by any command.
- **The base URL is the constant `https://api.enablebanking.com`.** It is not configurable.
- **Token:** RS256, header `kid` = the application id, claims `iss: "enablebanking.com"`, `aud: "api.enablebanking.com"`, `iat`, `exp`. Lifetime one hour.
- **The private key arrives as `EB_PRIVATE_KEY`, the PEM base64-encoded.** There is no path variant.
- **Timestamps are UTC in whole seconds,** `YYYY-MM-DDTHH:MM:SSZ`. Dates sent to the API are UTC dates.
- **Output holds keys, dates, counts and codes only.** Never an amount, an IBAN, a name, a description, a session id or an account `uid`. Lines this workspace composes hold no transaction identifier; an error from `@money/shared` may name a record by its identity.
- **An API error's `message` and `detail` are never kept, logged or thrown.** Only the HTTP status and an `error` code matching `^[A-Z_]+$`.
- **Only the project's own errors have their message printed:** `SyncError` and its subclasses, `ArchiveError`, `MergeError`. Any other error prints its class name and `code`.
- **No bank is named anywhere:** code, tests, commit messages. Made-up banks are `bnka` (`Example Bank`) and `bnkb` (`Other Example Bank`). The fake bank's website is `https://bank.example`.
- **Every invented IBAN has check digits `00`** (`NL00...`).
- **Never read or write under `tmp/`.** It holds the sandbox key. Tests use `mkdtemp` under the system temporary directory.
- **Tests run through `npm test`**, which pins `TZ=Europe/Amsterdam`. Never a bare `node --test`.
- **Before every commit:** `npm run format`, then commit. The pre-commit hook runs typecheck, lint, format check and the tests on the whole repository. Never `--no-verify`.
- **Conventional commits**, `type(scope): message`. Scopes used here: `sync`, `shared`, `tooling`; none when a change spans several.

## Review Focus

Inputs the spec implies but does not spell out. Each has a test in the task named.

1. **An IBAN written with spaces or in lower case**, in the configuration or by the bank, must still match its account during `auth`. Task 12.
2. **A bank that returns the same `continuation_key` twice** must stop the account with an error, never loop until the daily limit is spent. Task 11.
3. **A pasted redirect that is not a success**: surrounded by whitespace, carrying `error=...` because the user cancelled at the bank, or not an address at all. Each must stop `auth` with a clear message and store nothing. Task 12.
4. **A `valid_until` with a fraction of a second or a UTC offset** must be stored as a whole-second UTC timestamp, so the expiry check compares like with like. Task 5.
5. **A lock left by a dead run whose process id is now this process's own** (ids repeat inside a container) must be taken over, not treated as another live run. Task 9.

`sync/src/errors.ts`:

```ts
import { ArchiveError, MergeError } from "@money/shared";

// A failure the sync expects and explains. Its message is composed in this workspace from
// keys, dates, counts and codes, so it may be printed.
export class SyncError extends Error {
  override name = "SyncError";
}

const CONSENT_GONE = [
  "EXPIRED_SESSION",
  "REVOKED_SESSION",
  "CLOSED_SESSION",
  "SESSION_DOES_NOT_EXIST",
];

// What Enable Banking answered instead of a result. The response's own message and detail
// are deliberately not kept: they may say anything.
export class ApiError extends SyncError {
  override name = "ApiError";
  readonly status: number;
  readonly code: string | null;

  constructor(status: number, code: string | null) {
    super(`Enable Banking answered ${status}${code === null ? "" : ` ${code}`}`);
    this.status = status;
    this.code = code;
  }

  get consentGone(): boolean {
    return this.code !== null && CONSENT_GONE.includes(this.code);
  }
}

export const isExpected = (error: unknown): error is Error =>
  error instanceof SyncError || error instanceof ArchiveError || error instanceof MergeError;

// What may be printed about a failure. Job output leaves the host, and an error nobody
// composed here can quote bank data or a host path in its message.
export const describeError = (error: unknown): string => {
  if (isExpected(error)) return error.message;
  if (!(error instanceof Error)) return "unexpected failure";
  const code = (error as NodeJS.ErrnoException).code;
  const suffix = typeof code === "string" && /^[A-Z0-9_]+$/.test(code) ? ` ${code}` : "";
  return `unexpected ${error.constructor.name}${suffix}`;
};
```

```ts
export type Clock = () => Date;

// UTC in whole seconds, the one notation the archive accepts.
export const timestampOf = (date: Date): string => `${date.toISOString().slice(0, 19)}Z`;

// The UTC calendar date of a timestamp written by timestampOf.
export const dateOf = (timestamp: string): string => timestamp.slice(0, 10);

export const addDays = (date: string, days: number): string => {
  const moved = new Date(`${date}T00:00:00Z`);
  moved.setUTCDate(moved.getUTCDate() + days);
  return moved.toISOString().slice(0, 10);
};

// 2026-10-11T03:00:00Z becomes 20261011T030000Z: fixed width, so names sort by time.
export const runNameOf = (timestamp: string): string =>
  timestamp.replaceAll("-", "").replaceAll(":", "");
```

`sync/src/log.ts`:

```ts
export type Log = (event: string, fields?: Readonly<Record<string, string | number>>) => void;

// Keys, dates, counts and codes. Anything with a space, a comma or a letter outside ASCII
// is not one of those, and is refused rather than printed.
const SAFE = /^[A-Za-z0-9_.:-]*$/;

export const makeLog =
  (out: (line: string) => void): Log =>
  (event, fields = {}) => {
    const parts = Object.entries(fields).map(([key, value]) => {
      const text = String(value);
      if (!SAFE.test(text)) {
        throw new Error(`log field ${key} of ${event} holds something that may not be logged`);
      }
      return `${key}=${text}`;
    });
    out([event, ...parts].join(" "));
  };
```

`shared/src/archive/recover.ts`:

```ts
import { deepEqual } from "../util/equal.ts";
import { identityOf } from "./record.ts";
import type { ArchiveRecord } from "./record.ts";

// True when `later` is `earlier` after one or more further revisions: the same first
// sighting, `earlier`'s history as the start of `later`'s, and `earlier`'s current version
// as the entry that follows it.
const isAhead = (later: ArchiveRecord, earlier: ArchiveRecord): boolean =>
  later.first_seen === earlier.first_seen &&
  later.revisions.length > earlier.revisions.length &&
  deepEqual(later.revisions.slice(0, earlier.revisions.length), earlier.revisions) &&
  deepEqual(later.revisions[earlier.revisions.length].raw, earlier.raw);

// A write interrupted while a revised record moved to another year leaves two copies: the
// earlier version in the year it left and the revised one in the year it reached. Given two
// copies, returns the one to keep, or null when they are not that pair. Never guesses.
export const laterCopy = (a: ArchiveRecord, b: ArchiveRecord): ArchiveRecord | null => {
  if (identityOf(a) !== identityOf(b)) return null;
  if (isAhead(a, b)) return a;
  if (isAhead(b, a)) return b;
  return null;
};
```

```ts
import { createPrivateKey } from "node:crypto";
import type { KeyObject } from "node:crypto";

export type Environment = Readonly<Record<string, string | undefined>>;

export type Settings = {
  appId: string;
  privateKey: KeyObject;
  redirectUrl: string;
  configPath: string;
  dataDir: string;
  stateDir: string;
  lookbackDays: number;
  consentWarnDays: number;
};

export type SettingsResult = { ok: true; settings: Settings } | { ok: false; problems: string[] };

// The key travels as the PEM file base64-encoded, because the host delivers secrets as
// environment variables and a PEM has line breaks.
const readKey = (encoded: string, problems: string[]): KeyObject | null => {
  const refuse = (): null => {
    problems.push("EB_PRIVATE_KEY is not a base64-encoded PEM private key");
    return null;
  };
  if (!/^[A-Za-z0-9+/=\s]+$/.test(encoded)) return refuse();
  try {
    const key = createPrivateKey(Buffer.from(encoded, "base64").toString("utf8"));
    if (key.asymmetricKeyType !== "rsa") {
      problems.push("EB_PRIVATE_KEY is not an RSA key");
      return null;
    }
    return key;
  } catch {
    return refuse();
  }
};

// Returns every problem at once. A message names a variable and never repeats its value.
export const readSettings = (env: Environment): SettingsResult => {
  const problems: string[] = [];
  const text = (name: string): string => {
    const value = env[name];
    if (value === undefined || value === "") {
      problems.push(`${name} is not set`);
      return "";
    }
    return value;
  };
  const wholeNumber = (name: string, fallback: number): number => {
    const value = env[name];
    if (value === undefined || value === "") return fallback;
    if (!/^\d+$/.test(value)) {
      problems.push(`${name} must be a whole number, 0 or more`);
      return fallback;
    }
    return Number(value);
  };

  const appId = text("EB_APP_ID");
  const encodedKey = text("EB_PRIVATE_KEY");
  const privateKey = encodedKey === "" ? null : readKey(encodedKey, problems);
  const redirectUrl = text("EB_REDIRECT_URL");
  if (
    redirectUrl !== "" &&
    !(URL.canParse(redirectUrl) && new URL(redirectUrl).protocol === "https:")
  ) {
    problems.push("EB_REDIRECT_URL must be an https address");
  }
  const configPath = text("CONFIG_PATH");
  const dataDir = text("DATA_DIR");
  const stateDir = text("STATE_DIR");
  const lookbackDays = wholeNumber("LOOKBACK_DAYS", 30);
  const consentWarnDays = wholeNumber("CONSENT_WARN_DAYS", 14);

  if (problems.length > 0 || privateKey === null) return { ok: false, problems };
  return {
    ok: true,
    settings: {
      appId,
      privateKey,
      redirectUrl,
      configPath,
      dataDir,
      stateDir,
      lookbackDays,
      consentWarnDays,
    },
  };
};
```

```ts
import { readFile, stat } from "node:fs/promises";

import { validateConfig } from "@money/shared";
import type { Config } from "@money/shared";

import { readSettings } from "./env.ts";
import type { Environment, Settings } from "./env.ts";
import { SyncError } from "./errors.ts";

const codeOf = (error: unknown): string | undefined =>
  error instanceof Error ? (error as NodeJS.ErrnoException).code : undefined;

const isDirectory = async (path: string): Promise<boolean> => {
  try {
    return (await stat(path)).isDirectory();
  } catch (error) {
    if (codeOf(error) === "ENOENT" || codeOf(error) === "ENOTDIR") return false;
    throw error;
  }
};

// The configuration, or null with its problems added to the list.
const readConfig = async (path: string, problems: string[]): Promise<Config | null> => {
  let text: string;
  try {
    text = await readFile(path, "utf8");
  } catch (error) {
    if (codeOf(error) !== "ENOENT" && codeOf(error) !== "EISDIR") throw error;
    problems.push("CONFIG_PATH does not name a file");
    return null;
  }
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch {
    // The parser's own message quotes the file, which names real banks and accounts.
    problems.push("the configuration file is not valid JSON");
    return null;
  }
  const result = validateConfig(parsed);
  if (result.ok) return result.config;
  problems.push(...result.problems.map((problem) => `configuration: ${problem}`));
  return null;
};

// Everything a command needs before it does anything, or one error that lists every
// problem. A missing directory is an error and is never created: in production a missing
// mount would otherwise read as an empty archive.
export const loadStartup = async (
  env: Environment,
): Promise<{ settings: Settings; config: Config }> => {
  const result = readSettings(env);
  if (!result.ok) throw new SyncError(result.problems.join("\n"));
  const { settings } = result;

  const problems: string[] = [];
  if (!(await isDirectory(settings.dataDir))) {
    problems.push("DATA_DIR does not name an existing directory");
  }
  if (!(await isDirectory(settings.stateDir))) {
    problems.push("STATE_DIR does not name an existing directory");
  }
  const config = await readConfig(settings.configPath, problems);
  if (problems.length > 0 || config === null) throw new SyncError(problems.join("\n"));
  return { settings, config };
};
```

```ts
import { createSign } from "node:crypto";
import type { KeyObject } from "node:crypto";

// Enable Banking allows at most 24 hours. A run takes minutes, and a token is minted per
// run, so an hour is ample and a leaked one is soon worthless.
export const TOKEN_LIFETIME_SECONDS = 3600;

const encode = (value: unknown): string => Buffer.from(JSON.stringify(value)).toString("base64url");

export const mintToken = (key: KeyObject, appId: string, now: Date): string => {
  const issued = Math.floor(now.getTime() / 1000);
  const head = encode({ typ: "JWT", alg: "RS256", kid: appId });
  const claims = encode({
    iss: "enablebanking.com",
    aud: "api.enablebanking.com",
    iat: issued,
    exp: issued + TOKEN_LIFETIME_SECONDS,
  });
  const signature = createSign("RSA-SHA256").update(`${head}.${claims}`).sign(key, "base64url");
  return `${head}.${claims}.${signature}`;
};
```

```ts
import { isIsoDate, isObject, isText } from "@money/shared";
import type { Incoming } from "@money/shared";

import { SyncError } from "../errors.ts";
import { timestampOf } from "../time.ts";

// A response that is not what the code was written for. Nothing is guessed from it.
export class ResponseError extends SyncError {
  override name = "ResponseError";
}

export const isJson = (text: string): boolean => {
  try {
    JSON.parse(text);
    return true;
  } catch {
    return false;
  }
};

type Reviver = (this: unknown, key: string, value: unknown) => unknown;

// Node passes the reviver a third argument holding each primitive's source text.
const keepNumbersExact = (_key: string, value: unknown, context?: { source?: string }): unknown => {
  if (typeof value === "number" && JSON.stringify(value) !== context?.source) {
    throw new ResponseError("holds a number that would not survive being stored");
  }
  return value;
};

// Parses text, refusing any number that JSON would write back differently (1.10, an
// integer too large to hold). `raw` is compared with a copy that has been through JSON, so
// such a number would show as a revision on every later night.
export const parseExact = (text: string, where: string): unknown => {
  try {
    return JSON.parse(text, keepNumbersExact as Reviver) as unknown;
  } catch (error) {
    if (error instanceof ResponseError) throw new ResponseError(`${where} ${error.message}`);
    // The parser's own message can quote the text.
    throw new ResponseError(`${where} is not valid JSON`);
  }
};

export type Page = { transactions: readonly unknown[]; continuationKey: string | null };

export const checkPage = (value: unknown, where: string): Page => {
  if (!isObject(value)) throw new ResponseError(`${where} is not an object`);
  if (!Array.isArray(value.transactions)) {
    throw new ResponseError(`${where}: transactions is not a list`);
  }
  const key = value.continuation_key;
  if (key !== undefined && key !== null && !isText(key)) {
    throw new ResponseError(`${where}: continuation_key is not a text`);
  }
  return {
    transactions: value.transactions as unknown[],
    continuationKey: isText(key) ? key : null,
  };
};

// The booked transactions of a page, each with the identifier and booking date the archive
// files it under. Anything not booked is counted and left out. A booked transaction
// without its identifier or date stops the page: identity never falls back on content.
export const readTransactions = (
  page: Page,
  where: string,
): { booked: Incoming[]; skipped: number } => {
  const booked: Incoming[] = [];
  let skipped = 0;
  page.transactions.forEach((value, index) => {
    const at = `${where}, transaction ${index + 1}`;
    if (!isObject(value)) throw new ResponseError(`${at} is not an object`);
    if (!isText(value.status)) throw new ResponseError(`${at} has no status`);
    if (value.status !== "BOOK") {
      skipped += 1;
      return;
    }
    if (!isText(value.entry_reference)) {
      throw new ResponseError(`${at} is booked without an entry_reference`);
    }
    if (!isText(value.booking_date) || !isIsoDate(value.booking_date)) {
      throw new ResponseError(`${at} is booked without a usable booking_date`);
    }
    booked.push({ id: value.entry_reference, date: value.booking_date, raw: value });
  });
  return { booked, skipped };
};

export type Aspsp = {
  name: string;
  country: string;
  maximumConsentValidity: number;
  requiredPsuHeaders: string[];
};

const HEADER_NAME = /^[A-Za-z][A-Za-z-]*$/;

// The one bank asked for, from GET /aspsps. Other entries are not judged: an oddity in a
// bank nobody uses must not stop an authorisation.
export const findAspsp = (value: unknown, name: string, country: string): Aspsp | null => {
  if (!isObject(value) || !Array.isArray(value.aspsps)) {
    throw new ResponseError("the list of banks is not a list");
  }
  for (const [index, item] of (value.aspsps as unknown[]).entries()) {
    if (!isObject(item)) {
      throw new ResponseError(`the list of banks, entry ${index + 1} is not an object`);
    }
    if (item.name !== name || item.country !== country) continue;
    const validity = item.maximum_consent_validity;
    if (typeof validity !== "number" || !Number.isInteger(validity) || validity <= 0) {
      throw new ResponseError(
        "the bank's maximum_consent_validity is not a whole number of seconds",
      );
    }
    const headers: unknown = item.required_psu_headers ?? [];
    if (
      !Array.isArray(headers) ||
      !headers.every((header) => typeof header === "string" && HEADER_NAME.test(header))
    ) {
      throw new ResponseError("the bank's required_psu_headers is not a list of header names");
    }
    return {
      name,
      country,
      maximumConsentValidity: validity,
      requiredPsuHeaders: headers as string[],
    };
  }
  return null;
};

export const checkAuthStart = (value: unknown): { url: string } => {
  if (
    !isObject(value) ||
    !isText(value.url) ||
    !URL.canParse(value.url) ||
    new URL(value.url).protocol !== "https:"
  ) {
    throw new ResponseError("the authorisation has no https address to open");
  }
  return { url: value.url };
};

export type Session = {
  sessionId: string;
  validUntil: string;
  accounts: { iban: string | null; uid: string | null }[];
};

export const checkSession = (value: unknown): Session => {
  if (!isObject(value)) throw new ResponseError("the session is not an object");
  const sessionId = value.session_id;
  if (!isText(sessionId) || !/^[A-Za-z0-9-]+$/.test(sessionId)) {
    throw new ResponseError("the session has no usable session_id");
  }
  const until = isObject(value.access) ? value.access.valid_until : undefined;
  if (!isText(until) || Number.isNaN(Date.parse(until))) {
    throw new ResponseError("the session has no usable access.valid_until");
  }
  if (!Array.isArray(value.accounts)) {
    throw new ResponseError("the session's accounts is not a list");
  }
  const accounts = (value.accounts as unknown[]).map((account, index) => {
    if (!isObject(account)) {
      throw new ResponseError(`the session's accounts, entry ${index + 1} is not an object`);
    }
    const id = account.account_id;
    return {
      iban: isObject(id) && isText(id.iban) ? id.iban : null,
      uid: isText(account.uid) ? account.uid : null,
    };
  });
  return { sessionId, validUntil: timestampOf(new Date(until)), accounts };
};
```

```ts
import { addDays, dateOf } from "./time.ts";

export type DatedWindow = { strategy: "default"; dateFrom: string; dateTo: string };
export type Window = { strategy: "longest" } | DatedWindow;

// What to ask a bank for. An account with no recorded success is asked for the longest
// period the bank will give: that is a first fetch, a backfill that died, or lost state.
// Otherwise the window is anchored on the last success, so missed nights catch up on their
// own, and reaches back further by the lookback, because banks book late. Both times are
// UTC timestamps, and the dates sent are UTC dates.
export const fetchWindow = (
  lastSuccess: string | undefined,
  now: string,
  lookbackDays: number,
): Window =>
  lastSuccess === undefined
    ? { strategy: "longest" }
    : {
        strategy: "default",
        dateFrom: addDays(dateOf(lastSuccess), -lookbackDays),
        dateTo: dateOf(now),
      };
```

```ts
import type { ArchiveRecord } from "@money/shared";

import type { DatedWindow } from "./window.ts";

// The ids of stored records that a completed fetch of this window should have returned and
// did not. The merge cannot see this, because it does not know the window. The records are
// kept either way; this only says that a bank withdrew a booking or changed an identifier.
export const missingIds = (
  stored: readonly ArchiveRecord[],
  fetched: ReadonlySet<string>,
  window: DatedWindow,
): string[] =>
  stored
    .filter(
      (record) =>
        record.date >= window.dateFrom && record.date <= window.dateTo && !fetched.has(record.id),
    )
    .map((record) => record.id)
    .toSorted();

// A missing record alerts once, not on every night it stays inside the lookback.
export const newlyMissing = (missing: readonly string[], reported: readonly string[]): string[] =>
  missing.filter((id) => !reported.includes(id));
```

```ts
export type Consent = { expired: boolean; daysLeft: number; warn: boolean };

const DAY = 86_400_000;

// Where a consent stands at an instant. Both times are UTC timestamps.
export const consentAt = (validUntil: string, now: string, warnDays: number): Consent => {
  const left = Date.parse(validUntil) - Date.parse(now);
  return {
    expired: left <= 0,
    daysLeft: Math.max(0, Math.floor(left / DAY)),
    warn: left <= warnDays * DAY,
  };
};
```

```ts
import { isObject } from "@money/shared";

import { ApiError, SyncError } from "../errors.ts";
import type { Window } from "../window.ts";
import { checkAuthStart, checkSession, findAspsp, parseExact } from "./responses.ts";
import type { Aspsp, Session } from "./responses.ts";

// As much of `fetch` as the client uses. The built-in fetch satisfies it, and so does the
// fake bank.
export type Fetch = (
  url: string,
  init: { method: string; headers: Record<string, string>; body?: string; signal?: AbortSignal },
) => Promise<{ status: number; text: () => Promise<string> }>;

// Sandbox and production share this address. Which one a request reaches is decided by the
// application the token names.
export const BASE_URL = "https://api.enablebanking.com";

// A deep backfill makes the bank work, so the limit is generous. There is no retry: banks
// allow few unattended fetches a day.
const TIMEOUT_MS = 120_000;

export type AuthRequest = {
  aspsp: { name: string; country: string };
  state: string;
  redirectUrl: string;
  validUntil: string;
};

export type Client = {
  findAspsp: (name: string, country: string) => Promise<Aspsp | null>;
  startAuth: (request: AuthRequest) => Promise<{ url: string }>;
  createSession: (code: string) => Promise<Session>;
  transactionsPage: (
    uid: string,
    window: Window,
    continuationKey: string | null,
  ) => Promise<string>;
};

// The error code of a failed response, when it has one that is only capitals and
// underscores. The response's message and detail may say anything and are not read.
const errorCodeOf = (text: string): string | null => {
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch {
    return null;
  }
  return isObject(parsed) && typeof parsed.error === "string" && /^[A-Z_]+$/.test(parsed.error)
    ? parsed.error
    : null;
};

export const makeClient = (fetch: Fetch, token: string): Client => {
  const send = async (method: "GET" | "POST", path: string, body?: unknown): Promise<string> => {
    const headers: Record<string, string> = {
      authorization: `Bearer ${token}`,
      accept: "application/json",
    };
    if (body !== undefined) headers["content-type"] = "application/json";
    let status: number;
    let text: string;
    try {
      const response = await fetch(`${BASE_URL}${path}`, {
        method,
        headers,
        ...(body === undefined ? {} : { body: JSON.stringify(body) }),
        signal: AbortSignal.timeout(TIMEOUT_MS),
      });
      status = response.status;
      text = await response.text();
    } catch (error) {
      const kind = error instanceof Error ? error.constructor.name : "unknown";
      throw new SyncError(`no answer from Enable Banking (${kind})`);
    }
    if (status !== 200) throw new ApiError(status, errorCodeOf(text));
    return text;
  };

  return {
    findAspsp: async (name, country) => {
      const text = await send("GET", `/aspsps?${new URLSearchParams({ country }).toString()}`);
      return findAspsp(parseExact(text, "the list of banks"), name, country);
    },
    startAuth: async (request) => {
      const text = await send("POST", "/auth", {
        access: { valid_until: request.validUntil, balances: false, transactions: true },
        aspsp: request.aspsp,
        state: request.state,
        redirect_url: request.redirectUrl,
        psu_type: "personal",
      });
      return checkAuthStart(parseExact(text, "the authorisation"));
    },
    createSession: async (code) => {
      const text = await send("POST", "/sessions", { code });
      return checkSession(parseExact(text, "the session"));
    },
    transactionsPage: (uid, window, continuationKey) => {
      const query = new URLSearchParams({ transaction_status: "BOOK" });
      if (window.strategy === "longest") {
        query.set("strategy", "longest");
      } else {
        query.set("date_from", window.dateFrom);
        query.set("date_to", window.dateTo);
      }
      if (continuationKey !== null) query.set("continuation_key", continuationKey);
      return send("GET", `/accounts/${encodeURIComponent(uid)}/transactions?${query.toString()}`);
    },
  };
};
```

```ts
// Writes to a dot-prefixed neighbour and renames it into place, so the file is the old
// version or the new one and never part of each. The directory must exist.
export const writeAtomic = async (path: string, text: string): Promise<void> => {

  await writeFile(temporary, text, { flush: true });
```

```ts
// The sync's working area, $DATA_DIR/.inbox. Every page a bank returns is written here, as
// received, before the next one is asked for, and merged from here afterwards. Nothing a
// bank sent can then be lost between receiving it and merging it.
import { mkdir, readdir, readFile, rm } from "node:fs/promises";
import { join } from "node:path";

import { isIsoDate, isObject, isTimestamp } from "@money/shared";

import { writeAtomic } from "./atomic.ts";
import { SyncError } from "./errors.ts";
import type { Window } from "./window.ts";

// Written last. A run that has one was received in full.
export type Marker = { started: string; window: Window; pages: number };

export type InboxRun = { name: string; marker: Marker | null; pages: string[] };

const RUN = /^\d{8}T\d{6}Z$/;
const PAGE = /^([1-9]\d*)\.json$/;
const MARKER = "complete.json";

const runDir = (dataDir: string, account: string, run: string): string =>
  join(dataDir, ".inbox", account, run);

export const writePage = async (
  dataDir: string,
  account: string,
  run: string,
  number: number,
  text: string,
): Promise<void> => {
  const dir = runDir(dataDir, account, run);
  await mkdir(dir, { recursive: true });
  await writeAtomic(join(dir, `${number}.json`), text);
};

export const completeRun = (
  dataDir: string,
  account: string,
  run: string,
  marker: Marker,
): Promise<void> =>
  writeAtomic(join(runDir(dataDir, account, run), MARKER), `${JSON.stringify(marker, null, 2)}\n`);

export const removeRun = (dataDir: string, account: string, run: string): Promise<void> =>
  rm(runDir(dataDir, account, run), { recursive: true });

// A directory's names, without anything dot-prefixed. A missing directory is empty.
const visible = async (dir: string): Promise<string[]> => {
  try {
    return (await readdir(dir)).filter((name) => !name.startsWith(".")).toSorted();
  } catch (error) {
    if (error instanceof Error && (error as NodeJS.ErrnoException).code === "ENOENT") return [];
    throw error;
  }
};

const isWindow = (value: unknown): value is Window =>
  isObject(value) &&
  (value.strategy === "longest" ||
    (value.strategy === "default" &&
      typeof value.dateFrom === "string" &&
      isIsoDate(value.dateFrom) &&
      typeof value.dateTo === "string" &&
      isIsoDate(value.dateTo)));

const readMarker = (text: string, where: string): Marker => {
  const refuse = (): never => {
    throw new SyncError(`${where}: the marker is not one the sync wrote`);
  };
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch {
    return refuse();
  }
  if (!isObject(parsed)) return refuse();
  const { started, window, pages } = parsed;
  if (typeof started !== "string" || !isTimestamp(started)) return refuse();
  if (!isWindow(window)) return refuse();
  if (typeof pages !== "number" || !Number.isInteger(pages) || pages < 1) return refuse();
  return { started, window, pages };
};

// Every run in an account's inbox, oldest first, with the text of each page. A run's name
// is its start time in a fixed width, so sorting the names sorts the runs.
export const listRuns = async (dataDir: string, account: string): Promise<InboxRun[]> => {
  const root = join(dataDir, ".inbox", account);
  const runs: InboxRun[] = [];
  for (const name of await visible(root)) {
    if (!RUN.test(name)) {
      throw new SyncError(`the inbox of ${account} holds something that is not a run`);
    }
    const where = `${account}, run ${name}`;
    const files = await visible(join(root, name));
    const numbers: number[] = [];
    for (const file of files) {
      if (file === MARKER) continue;
      const match = PAGE.exec(file);
      if (match === null) throw new SyncError(`${where} holds something that is not a page`);
      numbers.push(Number(match[1]));
    }
    numbers.sort((a, b) => a - b);
    numbers.forEach((number, index) => {
      if (number !== index + 1) throw new SyncError(`${where}: page ${index + 1} is absent`);
    });
    const pages: string[] = [];
    for (const number of numbers) {
      pages.push(await readFile(join(root, name, `${number}.json`), "utf8"));
    }
    let marker: Marker | null = null;
    if (files.includes(MARKER)) {
      marker = readMarker(await readFile(join(root, name, MARKER), "utf8"), where);
      if (marker.pages !== pages.length) {
        throw new SyncError(
          `${where}: the marker counts ${marker.pages} pages and ${pages.length} are there`,
        );
      }
    }
    runs.push({ name, marker, pages });
  }
  return runs;
};
```

```ts
// What the sync remembers between runs: per bank, the session and what each account has
// reached. Rebuildable by running auth again, and never backed up, since it holds a live
// session id.
import { readFile } from "node:fs/promises";
import { join } from "node:path";

import { ACCOUNT_KEY, isObject, isText, isTimestamp } from "@money/shared";

import { writeAtomic } from "./atomic.ts";
import { isJson } from "./enablebanking/responses.ts";
import { SyncError } from "./errors.ts";

export type AccountState = {
  // The bank's id for the account under the current session. It changes with every consent.
  uid: string;
  // The start of the last fetch that was received in full and written. Absent until then.
  last_success?: string;
  // Ids of stored records the last window fetch should have returned and did not.
  missing: string[];
};

export type BankState = {
  session_id: string;
  valid_until: string;
  accounts: Record<string, AccountState>;
};

const isAccountState = (value: unknown): value is AccountState =>
  isObject(value) &&
  isText(value.uid) &&
  (value.last_success === undefined ||
    (typeof value.last_success === "string" && isTimestamp(value.last_success))) &&
  Array.isArray(value.missing) &&
  value.missing.every(isText);

const isBankState = (value: unknown): value is BankState =>
  isObject(value) &&
  isText(value.session_id) &&
  typeof value.valid_until === "string" &&
  isTimestamp(value.valid_until) &&
  isObject(value.accounts) &&
  Object.entries(value.accounts).every(
    ([key, account]) => ACCOUNT_KEY.test(key) && isAccountState(account),
  );

const pathOf = (stateDir: string, bank: string): string => join(stateDir, `${bank}.json`);

export const readState = async (stateDir: string, bank: string): Promise<BankState | null> => {
  let text: string;
  try {
    text = await readFile(pathOf(stateDir, bank), "utf8");
  } catch (error) {
    if (error instanceof Error && (error as NodeJS.ErrnoException).code === "ENOENT") return null;
    throw error;
  }
  // Text that is not JSON gets the same refusal as any other state the sync did not write.
  const parsed: unknown = isJson(text) ? JSON.parse(text) : null;
  if (!isBankState(parsed)) {
    throw new SyncError(
      `the stored state of ${bank} is not what the sync wrote. Remove it and run: auth ${bank}`,
    );
  }
  return parsed;
};

export const writeState = (stateDir: string, bank: string, state: BankState): Promise<void> =>
  writeAtomic(pathOf(stateDir, bank), `${JSON.stringify(state, null, 2)}\n`);

// The state after an authorisation. The session and every uid are new. What an account had
// already reached is kept, so a renewal continues from the last success instead of asking
// for the whole history again.
export const renewed = (
  previous: BankState | null,
  session: { sessionId: string; validUntil: string },
  uids: Readonly<Record<string, string>>,
): BankState => ({
  session_id: session.sessionId,
  valid_until: session.validUntil,
  accounts: Object.fromEntries(
    Object.keys(uids)
      .toSorted()
      .map((account): [string, AccountState] => {
        const before = previous?.accounts[account];
        return [
          account,
          {
            uid: uids[account],
            ...(before?.last_success === undefined ? {} : { last_success: before.last_success }),
            missing: before?.missing ?? [],
          },
        ];
      }),
  ),
});

export const withSuccess = (
  state: BankState,
  account: string,
  started: string,
  missing: readonly string[],
): BankState => ({
  ...state,
  accounts: {
    ...state.accounts,
    [account]: { uid: state.accounts[account].uid, last_success: started, missing: [...missing] },
  },
});
```

```ts
import { readFile, rm, writeFile } from "node:fs/promises";
import { join } from "node:path";

import { SyncError } from "./errors.ts";

// One writing command at a time. The archive's store assumes a single writer per account,
// and a manual run overlapping the nightly one would otherwise overwrite what the other
// had just written. Returns the function that releases the lock.
export const takeLock = async (
  stateDir: string,
  pid: number,
  isAlive: (pid: number) => boolean,
): Promise<() => Promise<void>> => {
  const path = join(stateDir, "lock");
  const create = async (): Promise<boolean> => {
    try {
      await writeFile(path, `${pid}\n`, { flag: "wx" });
      return true;
    } catch (error) {
      if (error instanceof Error && (error as NodeJS.ErrnoException).code === "EEXIST") {
        return false;
      }
      throw error;
    }
  };

  if (!(await create())) {
    const holder = Number((await readFile(path, "utf8")).trim());
    // A lock naming this process's own id was left by an earlier run with the same id:
    // ids repeat inside a container, and this run has not taken a lock yet.
    if (Number.isInteger(holder) && holder !== pid && isAlive(holder)) {
      throw new SyncError(
        "another run holds the lock in STATE_DIR. If none is running, remove the file named lock there.",
      );
    }
    await rm(path);
    if (!(await create())) throw new SyncError("the lock in STATE_DIR was taken by another run");
  }
  return () => rm(path);
};
```

### Task 10: The fake bank

**Files:**

- Create: `sync/testing/fake-bank.ts`, `sync/testing/fake-bank.test.ts`

**Interfaces:**

- Consumes: `Fetch`, `Clock`, `addDays`; `isObject` from `@money/shared`.
- Produces:
  - `type FakeVersion = { from: string; raw: Record<string, unknown> | null }`. `from` is a timestamp; `raw: null` means the bank withdrew the transaction from then on.
  - `type FakeAccount = { iban: string; transactions: FakeVersion[][] }`. Each inner list is one transaction's versions, oldest first.
  - `type FakeAspsp = { name: string; country: string; maximumConsentValidity: number; requiredPsuHeaders: string[]; unattendedDays: number; ignoresStatusFilter: boolean; accounts: FakeAccount[] }`
  - `type Failure = { status: number; error: string } | { network: true } | { body: string }`
  - `type RecordedRequest = { method: string; path: string; query: Record<string, string>; headers: Record<string, string>; body: string | undefined }`. Header names are lower case.
  - `type FakeBank = { fetch: Fetch; requests: RecordedRequest[]; served: { iban: string; raw: Record<string, unknown> }[]; pageSize: number; approve(url: string, options?: { only?: readonly string[] }): string; failRequest(n: number, failure: Failure): void; clearFailures(): void; revoke(aspspName: string): void }`
  - `makeFakeBank(options: { clock: Clock; publicKey: KeyObject; appId: string; redirectUrl: string; aspsps: FakeAspsp[] }): FakeBank`

The fake answers from its state: it is not a table of canned responses. Its shapes follow Enable Banking's API reference; Task 16 corrects them against the sandbox. The error body it returns always carries a recognisable `message` and `detail`, so that any test can assert neither was printed.

Behaviour to implement, exactly:

- **Token.** Every request must carry `Authorization: Bearer <token>` whose signature verifies against `publicKey`, with header `alg: "RS256"` and `kid` = `appId`, claims `iss: "enablebanking.com"`, `aud: "api.enablebanking.com"`, `iat <= now < exp`, and `exp - iat <= 86400`. Otherwise `401 UNAUTHORIZED_ACCESS`.
- **`GET /aspsps?country=`** lists the fake's banks in that country.
- **`POST /auth`** checks the bank exists (`400 WRONG_ASPSP_PROVIDED`), the redirect address is the registered one (`400 REDIRECT_URI_NOT_ALLOWED`), `state` is a non-empty text and `access.valid_until` is no later than now plus the bank's `maximumConsentValidity` (`400 WRONG_REQUEST_PARAMETERS`). It returns `https://bank.example/approve?authorization=<id>`.
- **`approve(url)`** plays the user: it returns the address the browser would land on, `<redirectUrl>?state=<state>&code=<code>`. With `only`, the consent covers just those IBANs.
- **`POST /sessions`** exchanges a code once (`400 WRONG_AUTHORIZATION_CODE` otherwise) for a session whose accounts each get a fresh `uid`. `access.valid_until` is returned with milliseconds, as `Date.prototype.toISOString` writes it.
- **`GET /accounts/<uid>/transactions`**: unknown `uid` is `404 ACCOUNT_DOES_NOT_EXIST`; a revoked session `401 REVOKED_SESSION`; one past `valid_until` `401 EXPIRED_SESSION`. A session authorised less than an hour ago reaches all history; an older one reaches `unattendedDays` back from today. With `strategy=longest` the period starts at the reach, or at `date_from` if that is later, and `date_to` is ignored. Without it, a `date_from` before the reach is `422 WRONG_TRANSACTIONS_PERIOD`. Results are the current version of each transaction at the time of the first page, filtered by booking date and by `transaction_status` unless the bank `ignoresStatusFilter`, sorted by booking date then `entry_reference`, `pageSize` to a page. A transaction with no text `booking_date` is always returned. A `continuation_key` is `k-<offset>-<time of first page in ms>`; any other is `400 WRONG_CONTINUATION_KEY`.
- **`failRequest(n, failure)`** makes the nth request from now fail: with an error response, a rejected promise (`network`), or a 200 response with the given body.
- **`revoke(name)`** revokes every session at that bank.
- Ids are `00000000-0000-4000-8000-<12-digit counter>`, so runs are reproducible.

```ts
// A bank behind the Enable Banking API, held in memory and handed to the code as its
// fetch. It answers from its state rather than from canned responses, so tests can
// generate histories freely. Its shapes follow the API reference, corrected against the
// sandbox. Everything in it is invented.
import { createVerify } from "node:crypto";
import type { KeyObject } from "node:crypto";

import { isObject, isText } from "@money/shared";

import type { Fetch } from "../src/enablebanking/client.ts";
import { addDays } from "../src/time.ts";
import type { Clock } from "../src/time.ts";

// One version of a transaction, current from `from` onward. A null `raw` means the bank
// withdrew the transaction from then on.
export type FakeVersion = { from: string; raw: Record<string, unknown> | null };
export type FakeAccount = { iban: string; transactions: FakeVersion[][] };

export type FakeAspsp = {
  name: string;
  country: string;
  maximumConsentValidity: number;
  requiredPsuHeaders: string[];
  // How far back a session reaches once the user is no longer present.
  unattendedDays: number;
  ignoresStatusFilter: boolean;
  accounts: FakeAccount[];
};

export type Failure = { status: number; error: string } | { network: true } | { body: string };

export type RecordedRequest = {
  method: string;
  path: string;
  query: Record<string, string>;
  headers: Record<string, string>;
  body: string | undefined;
};

export type FakeBank = {
  fetch: Fetch;
  requests: RecordedRequest[];
  // Every transaction the bank ever returned, in the order it returned them.
  served: { iban: string; raw: Record<string, unknown> }[];
  pageSize: number;
  // Plays the user approving at the bank: returns the address the browser lands on.
  approve: (url: string, options?: { only?: readonly string[] }) => string;
  // Makes the nth request from now fail.
  failRequest: (n: number, failure: Failure) => void;
  // Forgets every failure that has not happened yet.
  clearFailures: () => void;
  revoke: (aspspName: string) => void;
};

type Answer = { status: number; text: () => Promise<string> };
type Session = {
  aspsp: FakeAspsp;
  validUntil: number;
  authorisedAt: number;
  uids: Map<string, FakeAccount>;
  revoked: boolean;
};

const HOUR = 3_600_000;

export const makeFakeBank = (options: {
  clock: Clock;
  publicKey: KeyObject;
  appId: string;
  redirectUrl: string;
  aspsps: FakeAspsp[];
}): FakeBank => {
  const { clock, publicKey, appId, redirectUrl, aspsps } = options;
  const pending = new Map<string, { aspsp: FakeAspsp; state: string; validUntil: number }>();
  const codes = new Map<
    string,
    { aspsp: FakeAspsp; validUntil: number; only: readonly string[] | null }
  >();
  const sessions = new Map<string, Session>();
  const failures = new Map<number, Failure>();
  let counter = 0;
  let received = 0;

  const nextId = (): string => {
    counter += 1;
    return `00000000-0000-4000-8000-${String(counter).padStart(12, "0")}`;
  };
  const answer = (status: number, body: unknown): Answer => ({
    status,
    text: () => Promise.resolve(typeof body === "string" ? body : JSON.stringify(body)),
  });
  // The message and detail are there to be recognised: nothing may ever print them.
  const refuse = (status: number, error: string): Answer =>
    answer(status, {
      code: status,
      error,
      message: "Recognisable message about NL00BNKA0000000001",
      detail: "Recognisable detail",
    });

  const decode = (part: string): Record<string, unknown> => {
    const value: unknown = JSON.parse(Buffer.from(part, "base64url").toString());
    return isObject(value) ? value : {};
  };
  const tokenIsValid = (authorization: string | undefined): boolean => {
    const token = authorization?.startsWith("Bearer ") === true ? authorization.slice(7) : "";
    const [head, claims, signature, ...rest] = token.split(".");
    if (head === undefined || claims === undefined || signature === undefined || rest.length > 0) {
      return false;
    }
    try {
      const signed = createVerify("RSA-SHA256")
        .update(`${head}.${claims}`)
        .verify(publicKey, signature, "base64url");
      const header = decode(head);
      const body = decode(claims);
      const now = Math.floor(clock().getTime() / 1000);
      return (
        signed &&
        header.alg === "RS256" &&
        header.kid === appId &&
        body.iss === "enablebanking.com" &&
        body.aud === "api.enablebanking.com" &&
        typeof body.iat === "number" &&
        typeof body.exp === "number" &&
        body.iat <= now &&
        now < body.exp &&
        body.exp - body.iat <= 86_400
      );
    } catch {
      return false;
    }
  };

  const bank: FakeBank = {
    fetch: (url, init) => new Promise((resolve) => resolve(handle(url, init))),
    requests: [],
    served: [],
    pageSize: 100,
    approve: (url, approval = {}) => {
      const id = new URL(url).searchParams.get("authorization") ?? "";
      const waiting = pending.get(id);
      if (waiting === undefined) throw new Error("the fake bank has no such authorisation");
      pending.delete(id);
      const code = nextId();
      codes.set(code, {
        aspsp: waiting.aspsp,
        validUntil: waiting.validUntil,
        only: approval.only ?? null,
      });
      const query = new URLSearchParams({ state: waiting.state, code });
      return `${redirectUrl}?${query.toString()}`;
    },
    failRequest: (n, failure) => {
      failures.set(received + n, failure);
    },
    clearFailures: () => {
      failures.clear();
    },
    revoke: (aspspName) => {
      for (const session of sessions.values()) {
        if (session.aspsp.name === aspspName) session.revoked = true;
      }
    },
  };

  const listAspsps = (query: URLSearchParams): Answer =>
    answer(200, {
      aspsps: aspsps
        .filter((aspsp) => aspsp.country === query.get("country"))
        .map((aspsp) => ({
          name: aspsp.name,
          country: aspsp.country,
          maximum_consent_validity: aspsp.maximumConsentValidity,
          required_psu_headers: aspsp.requiredPsuHeaders,
        })),
    });

  const startAuth = (text: string | undefined): Answer => {
    const body: unknown = JSON.parse(text ?? "null");
    if (!isObject(body) || !isObject(body.aspsp) || !isObject(body.access)) {
      return refuse(400, "WRONG_REQUEST_PARAMETERS");
    }
    const wanted = body.aspsp;
    const aspsp = aspsps.find(
      (item) => item.name === wanted.name && item.country === wanted.country,
    );
    if (aspsp === undefined) return refuse(400, "WRONG_ASPSP_PROVIDED");
    if (body.redirect_url !== redirectUrl) return refuse(400, "REDIRECT_URI_NOT_ALLOWED");
    const validUntil = Date.parse(String(body.access.valid_until));
    const latest = clock().getTime() + aspsp.maximumConsentValidity * 1000;
    if (!isText(body.state) || Number.isNaN(validUntil) || validUntil > latest) {
      return refuse(400, "WRONG_REQUEST_PARAMETERS");
    }
    const id = nextId();
    pending.set(id, { aspsp, state: body.state, validUntil });
    return answer(200, {
      url: `https://bank.example/approve?authorization=${id}`,
      authorization_id: id,
    });
  };

  const createSession = (text: string | undefined): Answer => {
    const body: unknown = JSON.parse(text ?? "null");
    const code = isObject(body) && typeof body.code === "string" ? body.code : "";
    const approved = codes.get(code);
    if (approved === undefined) return refuse(400, "WRONG_AUTHORIZATION_CODE");
    codes.delete(code);
    const covered = approved.aspsp.accounts.filter(
      (account) => approved.only === null || approved.only.includes(account.iban),
    );
    const session: Session = {
      aspsp: approved.aspsp,
      validUntil: approved.validUntil,
      authorisedAt: clock().getTime(),
      uids: new Map(covered.map((account) => [nextId(), account])),
      revoked: false,
    };
    const sessionId = nextId();
    sessions.set(sessionId, session);
    return answer(200, {
      session_id: sessionId,
      accounts: [...session.uids].map(([uid, account]) => ({
        account_id: { iban: account.iban },
        uid,
        currency: "EUR",
        cash_account_type: "CACC",
        identification_hash: uid,
        identification_hashes: [uid],
      })),
      aspsp: { name: approved.aspsp.name, country: approved.aspsp.country },
      psu_type: "personal",
      access: { valid_until: new Date(approved.validUntil).toISOString() },
    });
  };

  const transactions = (uid: string, query: URLSearchParams): Answer => {
    const session = [...sessions.values()].find((item) => item.uids.has(uid));
    const account = session?.uids.get(uid);
    if (session === undefined || account === undefined) {
      return refuse(404, "ACCOUNT_DOES_NOT_EXIST");
    }
    const now = clock().getTime();
    if (session.revoked) return refuse(401, "REVOKED_SESSION");
    if (now >= session.validUntil) return refuse(401, "EXPIRED_SESSION");

    let offset = 0;
    let asOf = now;
    const key = query.get("continuation_key");
    if (key !== null) {
      const match = /^k-(\d+)-(\d+)$/.exec(key);
      if (match === null) return refuse(400, "WRONG_CONTINUATION_KEY");
      offset = Number(match[1]);
      asOf = Number(match[2]);
    }

    const today = new Date(now).toISOString().slice(0, 10);
    const fresh = now - session.authorisedAt < HOUR;
    const reach = fresh ? "0000-01-01" : addDays(today, -session.aspsp.unattendedDays);
    const longest = query.get("strategy") === "longest";
    const asked = query.get("date_from");
    if (!longest && asked !== null && asked < reach)
      return refuse(422, "WRONG_TRANSACTIONS_PERIOD");
    const from = asked === null || asked < reach ? reach : asked;
    const to = longest ? "9999-12-31" : (query.get("date_to") ?? "9999-12-31");
    const status = session.aspsp.ignoresStatusFilter ? null : query.get("transaction_status");

    const text = (value: unknown): string => (typeof value === "string" ? value : "");
    const matching = account.transactions
      .flatMap((versions) => {
        const version = versions.findLast((item) => Date.parse(item.from) <= asOf);
        return version === undefined || version.raw === null ? [] : [version.raw];
      })
      .filter((raw) => {
        const date = raw.booking_date;
        return typeof date !== "string" || (date >= from && date <= to);
      })
      .filter((raw) => status === null || raw.status === status)
      .toSorted((a, b) => {
        const left = `${text(a.booking_date)} ${text(a.entry_reference)}`;
        const right = `${text(b.booking_date)} ${text(b.entry_reference)}`;
        return left < right ? -1 : left > right ? 1 : 0;
      });

    const end = offset + bank.pageSize;
    const page = matching.slice(offset, end);
    for (const raw of page) bank.served.push({ iban: account.iban, raw });
    return answer(200, {
      transactions: page,
      continuation_key: end < matching.length ? `k-${end}-${asOf}` : null,
    });
  };

  const handle = (url: string, init: Parameters<Fetch>[1]): Answer => {
    received += 1;
    const address = new URL(url);
    const headers = Object.fromEntries(
      Object.entries(init.headers).map(([name, value]) => [name.toLowerCase(), value]),
    );
    bank.requests.push({
      method: init.method,
      path: address.pathname,
      query: Object.fromEntries(address.searchParams),
      headers,
      body: init.body,
    });

    const failure = failures.get(received);
    if (failure !== undefined) {
      failures.delete(received);
      if ("network" in failure) throw new TypeError("fetch failed");
      if ("body" in failure) return answer(200, failure.body);
      return refuse(failure.status, failure.error);
    }
    if (!tokenIsValid(headers.authorization)) return refuse(401, "UNAUTHORIZED_ACCESS");

    const route = `${init.method} ${address.pathname}`;
    if (route === "GET /aspsps") return listAspsps(address.searchParams);
    if (route === "POST /auth") return startAuth(init.body);
    if (route === "POST /sessions") return createSession(init.body);
    const account = /^\/accounts\/([^/]+)\/transactions$/.exec(address.pathname);
    if (init.method === "GET" && account !== null) {
      return transactions(decodeURIComponent(account[1]), address.searchParams);
    }
    return refuse(404, "WRONG_REQUEST_PARAMETERS");
  };

  return bank;
};
```

```ts
// One account's fetch, shared by auth and sync. Two phases joined only by the inbox:
// receive writes pages to disk, and the merge reads them from disk. A fresh fetch and one
// left behind by a run that died therefore take the same path.
import { merge, renderYearFiles } from "@money/shared";
import type { Config } from "@money/shared";
import { readAccountSource, recoverAccountSource, writeYearFiles } from "@money/shared/node";

import type { Context } from "../context.ts";
import {
  checkPage,
  isJson,
  parseExact,
  readTransactions,
  ResponseError,
} from "../enablebanking/responses.ts";
import { ApiError, isExpected, SyncError } from "../errors.ts";
import { completeRun, listRuns, removeRun, writePage } from "../inbox.ts";
import { missingIds, newlyMissing } from "../missing.ts";
import { readState, withSuccess, writeState } from "../state.ts";
import { runNameOf, timestampOf } from "../time.ts";
import { fetchWindow } from "../window.ts";
import type { Window } from "../window.ts";

// Bank key to the accounts the API is asked for: open, and known by an IBAN.
export const fetchable = (config: Config): Map<string, string[]> => {
  const byBank = new Map<string, string[]>();
  for (const [key, account] of Object.entries(config.accounts)) {
    if (account.iban === undefined || account.closed === true) continue;
    byBank.set(account.bank, [...(byBank.get(account.bank) ?? []), key]);
  }
  return byBank;
};

// Phase one. Each page is on disk, exactly as received, before the next is asked for. Only
// a 200 response that parses as JSON is a page.
const receive = async (
  context: Context,
  account: string,
  uid: string,
  started: string,
  window: Window,
): Promise<void> => {
  const { client, settings, deps } = context;
  const run = runNameOf(started);
  const seen = new Set<string>();
  let key: string | null = null;
  let number = 0;
  do {
    const text = await client.transactionsPage(uid, window, key);
    const where = `${account}, page ${number + 1}`;
    if (!isJson(text)) throw new ResponseError(`${where} is not valid JSON`);
    number += 1;
    await writePage(settings.dataDir, account, run, number, text);
    deps.checkpoint("page-written");
    key = checkPage(parseExact(text, where), where).continuationKey;
    if (key !== null) {
      // A bank that hands back a key it already gave would be asked forever.
      if (seen.has(key)) throw new ResponseError(`${where} repeats an earlier continuation_key`);
      seen.add(key);
    }
  } while (key !== null);
  await completeRun(settings.dataDir, account, run, { started, window, pages: number });
  deps.checkpoint("received");
};

// Phase two. Merges every run in the account's inbox, oldest first, and removes each once
// its data is written. An incomplete run is merged too: each page present is whole and is
// what the bank sent, and a partial batch cannot do harm because merge never deletes. Only
// a completed run records a success, and only a completed window is checked for records
// that should have come back. Returns how many records are newly missing.
const drainInbox = async (context: Context, bank: string, account: string): Promise<number> => {
  const { settings, deps, log } = context;
  let newly = 0;
  for (const run of await listRuns(settings.dataDir, account)) {
    const now = timestampOf(deps.clock());
    let records = await readAccountSource(settings.dataDir, account, "api");
    const fetched = new Set<string>();
    const counts = { added: 0, revised: 0, unchanged: 0, skipped: 0 };
    // One page at a time: if a transaction changed at the bank between two pages, the
    // later page revises the earlier one instead of contradicting it.
    run.pages.forEach((text, index) => {
      const where = `${account}, run ${run.name}, page ${index + 1}`;
      const page = readTransactions(checkPage(parseExact(text, where), where), where);
      const result = merge(records, page.booked, { account, source: "api" }, now);
      records = result.records;
      counts.added += result.added.length;
      counts.revised += result.revised.length;
      counts.unchanged += result.unchanged;
      counts.skipped += page.skipped;
      for (const item of page.booked) fetched.add(item.id);
    });
    await writeYearFiles(settings.dataDir, account, "api", renderYearFiles(records));
    deps.checkpoint("data-written");

    let missing = 0;
    if (run.marker !== null) {
      const state = await readState(settings.stateDir, bank);
      const entry = state?.accounts[account];
      if (state === null || entry === undefined) {
        throw new SyncError(
          `${account}: a fetch finished without a stored consent. Run: auth ${bank}`,
        );
      }
      const window = run.marker.window;
      // A backfill's reach is not known, so it cannot say what should have come back.
      const absent =
        window.strategy === "default" ? missingIds(records, fetched, window) : entry.missing;
      const fresh = window.strategy === "default" ? newlyMissing(absent, entry.missing) : [];
      await writeState(
        settings.stateDir,
        bank,
        withSuccess(state, account, run.marker.started, absent),
      );
      deps.checkpoint("state-written");
      missing = absent.length;
      newly += fresh.length;
      if (fresh.length > 0) {
        deps.out(
          `${account}: ${fresh.length} stored record(s) were absent from a fetch that should hold them. They are kept.`,
        );
      }
    }
    await removeRun(settings.dataDir, account, run.name);
    log("merged", {
      account,
      run: run.name,
      complete: run.marker === null ? "no" : "yes",
      pages: run.pages.length,
      ...counts,
      missing,
    });
  }
  return newly;
};

const fetchAccount = async (
  context: Context,
  bank: string,
  account: string,
  uid: string,
  backfill: boolean,
): Promise<number> => {
  const { settings, deps, log } = context;
  const recovered = await recoverAccountSource(settings.dataDir, account, "api");
  if (recovered > 0) log("recovered", { account, records: recovered });

  // What an earlier run left is merged before the bank is asked for anything new.
  let newly = await drainInbox(context, bank, account);

  const state = await readState(settings.stateDir, bank);
  // Read before the first request, so a transaction booked while the run is in progress
  // falls inside the next window.
  const started = timestampOf(deps.clock());
  // Draining may just have recorded a success from a run an earlier process left. `auth`
  // asks for the whole history regardless, for an account it found with none.
  const window: Window = backfill
    ? { strategy: "longest" }
    : fetchWindow(state?.accounts[account]?.last_success, started, settings.lookbackDays);
  log("fetching", {
    account,
    strategy: window.strategy,
    ...(window.strategy === "default" ? { from: window.dateFrom, to: window.dateTo } : {}),
  });
  await receive(context, account, uid, started, window);
  newly += await drainInbox(context, bank, account);
  return newly;
};

// Fetches each account in turn. An expected failure stops that account only, unless it
// says the consent is gone, which stops the rest of the bank. Anything unexpected is not
// caught: it stops the run.
export const fetchAccounts = async (
  context: Context,
  bank: string,
  accounts: readonly (readonly [string, string])[],
  backfill: ReadonlySet<string> = new Set(),
): Promise<{ failed: string[]; newlyMissing: number }> => {
  const { deps } = context;
  const failed: string[] = [];
  let newly = 0;
  for (const [index, [account, uid]] of accounts.entries()) {
    try {
      newly += await fetchAccount(context, bank, account, uid, backfill.has(account));
    } catch (error) {
      if (!isExpected(error)) throw error;
      failed.push(account);
      deps.out(`${account}: ${error.message}`);
      if (error instanceof ApiError && error.code === "WRONG_TRANSACTIONS_PERIOD") {
        deps.out(`${account}: the bank does not serve that period unattended. Run: auth ${bank}`);
      }
      if (error instanceof ApiError && error.consentGone) {
        deps.out(`${bank}: the consent is gone. Run: auth ${bank}`);
        failed.push(...accounts.slice(index + 1).map(([key]) => key));
        break;
      }
    }
  }
  return { failed, newlyMissing: newly };
};
```

```ts
import { SyncError } from "./errors.ts";

// Reads the code out of the address the user pastes back after approving at the bank.
// That page does not load; only its address matters. No message repeats what was pasted.
export const readRedirect = (pasted: string, redirectUrl: string, state: string): string => {
  const text = pasted.trim();
  if (!URL.canParse(text)) {
    throw new SyncError("that is not an address. Paste the whole address the browser was sent to.");
  }
  const landed = new URL(text);
  const expected = new URL(redirectUrl);
  if (landed.origin !== expected.origin || landed.pathname !== expected.pathname) {
    throw new SyncError("that is not the redirect address of this application");
  }
  const error = landed.searchParams.get("error");
  if (error !== null) {
    const code = /^[a-z_]+$/.test(error) ? ` (${error})` : "";
    throw new SyncError(`the bank did not grant the consent${code}`);
  }
  if (landed.searchParams.get("state") !== state) {
    throw new SyncError(
      "that address belongs to another authorisation: its state does not match. Start again.",
    );
  }
  const code = landed.searchParams.get("code");
  if (code === null || code === "") throw new SyncError("that address carries no code");
  return code;
};
```

```ts
// Starts or renews the consent for one bank, then fetches. Interactive: the user approves
// at the bank and pastes back the address the browser was sent to.
import type { Context } from "../context.ts";
import { SyncError } from "../errors.ts";
import { readRedirect } from "../redirect.ts";
import { readState, renewed, writeState } from "../state.ts";
import { dateOf, timestampOf } from "../time.ts";
import { fetchable, fetchAccounts } from "./account.ts";

// An IBAN as it is compared: people write them with spaces, banks without.
const plain = (iban: string): string => iban.replaceAll(/\s/g, "").toUpperCase();

export const runAuth = async (context: Context, bank: string): Promise<number> => {
  const { settings, config, client, deps, log } = context;
  // What was typed is not repeated: it may be anything.
  if (!Object.hasOwn(config.banks, bank)) {
    throw new SyncError("that bank is not in the configuration");
  }
  const accounts = fetchable(config).get(bank) ?? [];
  if (accounts.length === 0) {
    throw new SyncError(
      `${bank} has no open account with an iban, so there is nothing to authorise`,
    );
  }
  // Read first, so that state the sync cannot use is found before the user goes to the bank.
  const previous = await readState(settings.stateDir, bank);

  const { aspsp } = config.banks[bank];
  const listed = await client.findAspsp(aspsp.name, aspsp.country);
  if (listed === null) {
    throw new SyncError(
      `${bank}: Enable Banking lists no bank under the configured name and country`,
    );
  }
  const required = listed.requiredPsuHeaders.join(", ");
  deps.out(`PSU headers this bank lists as required: ${required === "" ? "none" : required}`);

  const state = deps.randomState();
  const validUntil = timestampOf(
    new Date(deps.clock().getTime() + listed.maximumConsentValidity * 1000),
  );
  const { url } = await client.startAuth({
    aspsp,
    state,
    redirectUrl: settings.redirectUrl,
    validUntil,
  });
  deps.out(
    "Open this address and approve. The browser is then sent to a page that does not load; that is expected.",
  );
  deps.out(url);
  const pasted = await deps.readLine("Paste the whole address of that page: ");
  const session = await client.createSession(readRedirect(pasted, settings.redirectUrl, state));

  const uids: Record<string, string> = {};
  const problems: string[] = [];
  for (const account of accounts) {
    const iban = plain(config.accounts[account].iban ?? "");
    const found = session.accounts.find((item) => item.iban !== null && plain(item.iban) === iban);
    if (found === undefined) problems.push(`${account}: the consent does not cover it`);
    else if (found.uid === null) {
      problems.push(`${account}: the consent covers it but gives no way to fetch it`);
    } else uids[account] = found.uid;
  }
  if (problems.length > 0) throw new SyncError(problems.join("\n"));

  await writeState(settings.stateDir, bank, renewed(previous, session, uids));
  log("authorised", {
    bank,
    accounts: accounts.length,
    ignored: session.accounts.length - accounts.length,
    until: dateOf(session.validUntil),
  });

  // At once, before returning: a bank may serve older history only while the user has
  // just authenticated, and that fetch may not be repeatable.
  const outcome = await fetchAccounts(
    context,
    bank,
    accounts.map((account) => [account, uids[account]] as const),
    // Decided from the state as it was found, before anything left in the inbox is merged:
    // a completed run from before the state was lost must not stand in for the history.
    new Set(accounts.filter((account) => previous?.accounts[account]?.last_success === undefined)),
  );
  if (outcome.failed.length > 0) {
    deps.out(
      `The consent is stored. Not fetched in full: ${outcome.failed.join(", ")}. Run sync to continue.`,
    );
    return 1;
  }
  return outcome.newlyMissing > 0 ? 1 : 0;
};
```

```ts
// The nightly run: every bank, and every open account the API can reach.
import { consentAt } from "../consent.ts";
import type { Context } from "../context.ts";
import { isExpected } from "../errors.ts";
import { readState } from "../state.ts";
import { timestampOf } from "../time.ts";
import { fetchable, fetchAccounts } from "./account.ts";

type Outcome = { failed: string[]; newlyMissing: number };

const syncBank = async (
  context: Context,
  bank: string,
  accounts: readonly string[],
  now: string,
): Promise<Outcome> => {
  const { settings, deps, log } = context;
  const state = await readState(settings.stateDir, bank);
  if (state === null) {
    deps.out(`${bank}: no consent is stored. Run: auth ${bank}`);
    return { failed: [bank], newlyMissing: 0 };
  }
  const consent = consentAt(state.valid_until, now, settings.consentWarnDays);
  if (consent.expired) {
    // Known without asking, and a request would only spend one of the day's few.
    deps.out(`${bank}: the consent has expired. Run: auth ${bank}`);
    return { failed: [bank], newlyMissing: 0 };
  }

  const failed: string[] = [];
  const covered: [string, string][] = [];
  for (const account of accounts) {
    const entry = state.accounts[account];
    if (entry === undefined) {
      failed.push(account);
      deps.out(`${account}: the stored consent does not cover it. Run: auth ${bank}`);
    } else covered.push([account, entry.uid]);
  }
  const outcome = await fetchAccounts(context, bank, covered);
  // A warning only. What alerts is `status`, which exits non-zero inside this window.
  if (consent.warn) log("consent-expiring", { bank, days: consent.daysLeft });
  return { failed: [...failed, ...outcome.failed], newlyMissing: outcome.newlyMissing };
};

// Banks fail separately, and so do accounts. Everything that can be done is done, and
// only then does the run exit non-zero, naming what failed.
export const runSync = async (context: Context): Promise<number> => {
  const { config, deps, log } = context;
  const now = timestampOf(deps.clock());
  const failed: string[] = [];
  let newlyMissing = 0;
  for (const [bank, accounts] of fetchable(config)) {
    try {
      const outcome = await syncBank(context, bank, accounts, now);
      failed.push(...outcome.failed);
      newlyMissing += outcome.newlyMissing;
    } catch (error) {
      if (!isExpected(error)) throw error;
      failed.push(bank);
      deps.out(`${bank}: ${error.message}`);
    }
  }
  log("done", { failed: failed.length, newly_missing: newlyMissing });
  if (failed.length > 0) deps.out(`failed: ${failed.join(", ")}`);
  return failed.length > 0 || newlyMissing > 0 ? 1 : 0;
};
```

```ts
import type { Context } from "../context.ts";
import { readState } from "../state.ts";
import { dateOf, timestampOf } from "../time.ts";

// Exits non-zero when a person is needed: a bank without a consent, or a consent that has
// expired or will within the warning window. In production nobody reads a warning, so the
// exit code is the warning.
export const runStatus = async (context: Context): Promise<number> => {
  const { settings, config, deps } = context;
  const now = timestampOf(deps.clock());
  let attention = false;
  for (const [bank, accounts] of fetchable(config)) {
    const state = await readState(settings.stateDir, bank);
    if (state === null) {
      deps.out(`${bank}: no consent is stored. Run: auth ${bank}`);
      attention = true;
      continue;
    }
    const consent = consentAt(state.valid_until, now, settings.consentWarnDays);
    const until = dateOf(state.valid_until);
    if (consent.expired) {
      deps.out(`${bank}: the consent expired on ${until}. Run: auth ${bank}`);
    } else {
      const renew = consent.warn ? `. Run: auth ${bank}` : "";
      deps.out(
        `${bank}: the consent lasts until ${until}, ${consent.daysLeft} days from now${renew}`,
      );
    }
    if (consent.warn) attention = true;
    for (const account of accounts) {
      const last = state.accounts[account]?.last_success;
      deps.out(
        last === undefined
          ? `  ${account}: never fetched in full`
          : `  ${account}: last fetched in full on ${dateOf(last)}`,
      );
    }
  }
  return attention ? 1 : 0;
};
```

### Task 14: The convergence property

**Files:**

- Create: `sync/src/convergence.test.ts`

**Interfaces:**

- Consumes: `makeWorld`, `booked`, `CRASHED`, `FakeAspsp`, `FakeVersion`, `Checkpoint`; `deepEqual`, `view` from `@money/shared`; `makeRandom`, `Random` from `@money/shared/testing`.
- Produces: nothing other tasks use.

The two claims the project rests on, stated over the real commands: however the nights fall and wherever a run dies, the archive ends up showing what one fetch of the bank's final state shows, and every version the bank ever returned is in it.

How the world is generated, and why:

- **One bank, one account**, a history of up to 14 transactions over 45 nights starting 2025-12-05, so every seed crosses a year boundary.
- **A transaction appears** an hour before some night's run, booked up to `LOOKBACK_DAYS` days earlier. That is what the lookback exists for, and the lookback is 0, 3 or 30 by seed.
- **45% of transactions change once**: most get a new amount and perhaps a new booking date up to 40 days either way, some are withdrawn.
- **Each night runs with probability one half**, sometimes twice. Three runs in ten are disturbed: a run dies at a random checkpoint, or a request fails with an error response or a broken connection.
- **It ends with lost state and a new `auth`**, which is a full backfill.
- **The fake bank's unattended reach is ten years**, so no window is refused. Refusal has its own scenario in Task 11.

```ts
  timestampOf(new Date(START + night * DAY + minutes * 60_000));

const bankWith = (transactions: FakeVersion[][]): FakeAspsp => ({
  name: "Example Bank",
  country: "NL",
  maximumConsentValidity: 180 * 86_400,
  requiredPsuHeaders: [],
  // Long enough that no window is refused: that has its own scenario.
  unattendedDays: 3650,
  ignoresStatusFilter: false,

type History = {
  transactions: FakeVersion[][];
  // Ids that never change, and ids the bank withdraws.
  steady: Set<string>;
  withdrawn: Set<string>;
};

const amount = (random: Random): Record<string, unknown> => ({
  transaction_amount: { currency: "EUR", amount: `${random.int(1, 500)}.00` },
});

const history = (random: Random, lookback: number): History => {
  const made: History = { transactions: [], steady: new Set(), withdrawn: new Set() };
  const count = random.int(0, 14);
  for (let index = 0; index < count; index++) {
    const id = `t${index}`;
    // Some transactions are older than the first authorisation.
    const appears = random.int(-20, NIGHTS - 2);
    // Banks book late, by at most the lookback: that is what the lookback is for.
    const date = addDays(dateOf(stamp(appears)), -random.int(0, lookback));
    const versions: FakeVersion[] = [
      { from: stamp(appears, -60), raw: booked(id, date, amount(random)) },
    ];
    if (random.chance(0.45)) {
      const from = stamp(random.int(appears + 1, NIGHTS - 1), -60);
      if (random.chance(0.3)) {
        versions.push({ from, raw: null });
        made.withdrawn.add(id);
      } else {
        const moved = random.chance(0.5) ? date : addDays(date, random.int(-40, 40));
        versions.push({ from, raw: booked(id, moved, amount(random)) });
      }
    } else {
      made.steady.add(id);
    }
    made.transactions.push(versions);
  }
  return made;
};

const current = (records: readonly ArchiveRecord[]) =>
  new Map(records.map((record) => [record.id, [record.date, record.raw]]));

const shown = (records: readonly ArchiveRecord[]) =>
  view(records, {}).map((item) => ({ ...item, first_seen: "", revised: false }));

type Tally = {
  crashes: number;
  failures: number;
  leftovers: number;
  revised: number;
  withdrawnKept: number;
};

const converge = async (seed: number): Promise<Tally> => {
  const random = makeRandom(seed);
  const lookback = random.pick([0, 3, 30]);
  const made = history(random, lookback);
  const world = await makeWorld({
    config,
    aspsps: [bankWith(made.transactions)],
    start: stamp(0),
    env: { LOOKBACK_DAYS: String(lookback) },
  });
  // A second machine that has never run, for the single fetch of the final state.
  const fresh = await makeWorld({
    config,
    aspsps: [bankWith(made.transactions)],
    start: stamp(NIGHTS),
  });
  const tally: Tally = { crashes: 0, failures: 0, leftovers: 0, revised: 0, withdrawnKept: 0 };
  try {
    world.bank.pageSize = random.int(1, 5);
    assert.equal(await world.run("auth", "bnka"), 0, `seed ${seed}: the first authorisation`);

    for (let night = 1; night < NIGHTS; night++) {
      if (!random.chance(0.5)) continue;
      const runs = random.chance(0.15) ? 2 : 1;
      for (let run = 0; run < runs; run++) {
        world.at(stamp(night, run * 5));
        if (random.chance(0.3)) {
          if (random.chance(0.5)) {
            world.crashAt = random.pick(POINTS);
          } else {
            const failure = random.chance(0.5)
              ? { status: 500, error: "ASPSP_ERROR" }
              : ({ network: true } as const);
            world.bank.failRequest(random.int(1, 2), failure);
            tally.failures += 1;
          }
        }
        if ((await world.run("sync")) === CRASHED) tally.crashes += 1;
        world.crashAt = null;
      }
    }

    // Before the final backfill, which would repair it: a transaction that never changed
    // and that the bank had by the last fetch recorded as a success is already here.
    const reached = (await world.state("bnka"))?.accounts[ACCOUNT].last_success ?? "";
    const before = new Set((await world.records(ACCOUNT)).map((record) => record.id));
    made.transactions.forEach((versions, index) => {
      const id = `t${index}`;
      if (!made.steady.has(id) || versions[0].from > reached) return;
      assert.ok(
        before.has(id),
        `seed ${seed}: ${id} was at the bank by the last full fetch and is not in the archive`,
      );
    });

    // The state is lost, and the user authorises again: a full backfill.
    world.bank.clearFailures();
    world.at(stamp(NIGHTS));
    await rm(join(world.stateDir, "bnka.json"));
    assert.notEqual(await world.run("auth", "bnka"), CRASHED, `seed ${seed}: the last backfill`);
    assert.equal(await fresh.run("auth", "bnka"), 0, `seed ${seed}: the single fetch`);

    const stored = await world.records(ACCOUNT);
    const expected = await fresh.records(ACCOUNT);
    const kept = stored.filter((record) => !made.withdrawn.has(record.id));

    // Convergence: apart from what the bank withdrew, the archive shows exactly what one
    // fetch of the final state shows.
    assert.deepEqual(current(kept), current(expected), `seed ${seed}: what is stored`);
    assert.deepEqual(shown(kept), shown(expected), `seed ${seed}: what is shown`);

    // Nothing is lost: every version the bank ever returned is the current one or a
    // revision, a withdrawn transaction included.
    for (const { raw } of world.bank.served) {
      const record = stored.find((item) => item.id === raw.entry_reference);
      const versions =
        record === undefined ? [] : [record.raw, ...record.revisions.map((item) => item.raw)];
      assert.ok(
        versions.some((version) => deepEqual(version, raw)),
        `seed ${seed}: a version the bank returned is not in the archive`,
      );
    }

    tally.leftovers = world.lines.filter((line) => line.includes("complete=no")).length;
    tally.revised = stored.filter((record) => record.revisions.length > 0).length;
    tally.withdrawnKept = stored.length - kept.length;
    return tally;
  } finally {
    await world.cleanup();
    await fresh.cleanup();
  }
};

test("however the nights fall and wherever a run dies, the archive converges and nothing is lost", async () => {

  for (const [what, count] of Object.entries(total)) {
    assert.ok(count > 0, `no run in ${SEEDS} seeds had any ${what}`);
  }
});
```

````markdown
Every fetch, backfill or nightly, has two phases, so that nothing a bank returned can be lost between receiving it and merging it. The inbox is the only way data moves from the first to the second: the merge reads pages from disk, never from memory, so a fresh fetch and one left by a run that died take the same path.

```text
$DATA_DIR/.inbox/<account key>/<run>/
  1.json  2.json  ...     the pages, exactly as received
  complete.json           the marker
```

`<run>` is the run's start time, `YYYYMMDDTHHMMSSZ`.

1. **Receive.** Each response with status 200 that parses as JSON is written, exactly as received, by temporary file and rename, before the next page is requested. When the last page is in, the marker is written: the run's start time, its window and its page count.
2. **Merge.** A run is merged into the year files, page by page, and then removed.

Before fetching, whatever the inbox already holds for the account is merged first:

- **A completed run** is merged as if it had just been fetched, and its success is recorded with the start time in its marker. The bank is not asked again.
- **An incomplete run is merged too.** Each page present is whole and is what the bank sent, and a partial batch cannot do harm, because the merge never deletes. No success is recorded for it and no missing-record check is made. A half-finished backfill's pages therefore reach the archive.
````
